The online version ([app.managecomp.org](https://app.managecomp.org)) offers the same features as the software, in the web browser. Competitions are stored on the server.

## Access by club

Each club (or committee) has an **access key**: it only sees and changes its own competitions. The key is entered when logging in; the software also uses it to connect referees' phones.

## Differences with the software

- no installation;
- several organisers can follow the same competition;
- printing through the browser ("Print", then the printer or PDF).
