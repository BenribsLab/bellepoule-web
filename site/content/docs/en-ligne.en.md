The online version ([app.managecomp.org](https://app.managecomp.org)) offers the same features as the software, in the web browser. Competitions are stored on the server.

## Account and access by club

1. On the login page, **Créer un compte** (create an account) tab: name, e-mail, club and password.
2. A server administrator **approves** the request; you then log in with your e-mail and password.

Each club only sees and changes its own competitions.

**My account › Club API keys** creates named keys ("club computer"…). A key connects the **desktop software** (referees on phones, piste screens) or a third-party application to your club; it can be removed at any time. Clubs with a key provided by the administrator can also log in with the key.

Server administrators have an **Administration** page: approving and removing accounts, statistics, open competitions.

## Differences with the software

- no installation;
- several organisers can follow the same competition;
- printing through the browser ("Print", then the printer or PDF);
- competitions are removed from the home page without being deleted ([First competition](@/docs/premiere-competition.md));
- the club's **Categories** page: general category model shared by all its competitions.
