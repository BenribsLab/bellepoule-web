ManageComp runs a fencing competition from start to finish: fencer check-in, the formula (pools, tables…), result entry, ranking and printing.

## The parts of ManageComp

| Part | Role | Where |
|---|---|---|
| **ManageComp** (software) | runs competitions on the scoring table's computer | Windows |
| **ManageComp online** | the same in a web browser, competitions shared by the club | [app.managecomp.org](https://app.managecomp.org) |
| **Organisation** | pistes, referees, schedule; built into the software and the online version | Organisation menu |
| **ManageComp Referee** | referees enter their bouts on their phone | [arbitre.managecomp.org](https://arbitre.managecomp.org), by QR code |
| **ManageComp Live** | scoreboard for each piste | web browser or piste box |

The computer and the phones communicate **through the server**: they do not need to share the same Wi-Fi network. The computer and the phones just need Internet access.

## How a competition runs

1. **Create** the competition: name, weapon, category, date ([First competition](@/docs/premiere-competition.md)).
2. **Check in**: import or enter fencers, mark who is present ([Check-in](@/docs/appel.md)).
3. **Build the formula**: pool rounds, tables, ranking ([The formula](@/docs/formule.md)).
4. **Fence the pools** then the **tables**, with pistes and referees ([Pools](@/docs/poules.md), [Tables](@/docs/tableaux.md), [Organisation](@/docs/organisation.md)).
5. **Publish** the final ranking and results ([Ranking and exports](@/docs/classement.md)).

## Compatibility with BellePoule

ManageComp is derived from BellePoule and keeps its computing rules. `.cotcot` files open in both programs, except those using features specific to ManageComp (youth training, team relays).
