## Classement général

La dernière phase de la formule établit le classement final de la compétition.

## Impressions

- **Classement final** ;
- **Résultats complets** : feuilles de poules, tableaux, classement ;
- pour un **entraînement des jeunes** : le classement puis chaque groupe avec ses poules et son tableau remplis.

## Exports

| Format | Usage |
|---|---|
| FFF | remontée des résultats à la Fédération française d'escrime ; **à partir de la place** décale les places (17 pour un tableau B qui classe à partir de la 17e place) |
| XML FIE | échange avec les autres logiciels et la FIE |
| AskFred | compétitions américaines |
| HTML | publication sur un site web |

## Publication

Les résultats peuvent être publiés automatiquement par FTP ou vers Escrime Info pendant la compétition.
