## General ranking

The last phase of the formula sets the competition's final ranking.

## Printing

- **Final ranking**;
- **Complete results**: pool sheets, tables, ranking;
- for a **youth training**: the ranking then each group with its pools and table filled in.

## Exports

| Format | Use |
|---|---|
| FFF | results for the French fencing federation; **from place** shifts the places (17 for a B table ranking from 17th place) |
| FIE XML | exchange with other software and the FIE |
| AskFred | American competitions |
| HTML | publishing on a website |

## Publishing

Results can be published automatically by FTP or to Escrime Info during the competition.
